## Что умеет

- **Подписки, которые действительно загружаются.** Многие провайдеры ограничивают число
  устройств и отдают серверы только клиенту, который назвал своё устройство. Quadra
  отправляет нужные заголовки (`x-hwid` и остальные), поэтому такие подписки приходят
  полным списком, а не заглушкой «приложение не поддерживается». Это можно отключить.
- **Ссылки и готовые конфигурации.** `vless://`, `vmess://`, `trojan://`, `ss://`, список в
  base64 или целая конфигурация Xray с балансировщиками и своей маршрутизацией: вставь,
  перетащи файл на окно или просто нажми Ctrl+V в любом месте.
- **Три режима.** Системный прокси, весь трафик через виртуальный адаптер (TUN) или только
  локальные порты SOCKS и HTTP.
- **Карта подключения.** Видно, где ты и где сервер. Статус «подключено» появляется только
  после того, как через туннель прошёл настоящий запрос.
- **Маршрутизация и исключения.** Домашняя сеть или целая страна напрямую, свои правила по
  доменам и адресам, список программ и сайтов, которые никогда не идут через сервер.
- **Свой вид.** Тёмная и светлая темы и любой акцентный цвет: за ним перекрашивается весь
  интерфейс вместе с картой.

Все соединения устанавливает [Xray-core](https://github.com/XTLS/Xray-core), поэтому работает
всё, что умеет Xray: REALITY, XHTTP, gRPC, WebSocket и остальное.

## Скачать

Установщик для своей системы бери в
[последнем релизе](https://github.com/Omibranch/quadra/releases/latest).

| Система | Файл | Примечание |
|---|---|---|
| Windows 10/11 | `Quadra_x.y.z_x64-setup.exe` | Ставится для текущего пользователя, права администратора не нужны |
| macOS, Apple silicon | `Quadra_x.y.z_aarch64.dmg` | Сборки не подписаны, см. ниже |
| macOS, Intel | `Quadra_x.y.z_x64.dmg` | |
| Linux | `.deb`, `.rpm` или `.AppImage` | Нужен WebKitGTK 4.1 |
| Android 8+ (эксперимент) | `Quadra_x.y.z_android-arm64.apk` | Ставится файлом, в Google Play его нет |

Сборки не подписаны сертификатом. Windows SmartScreen спросит один раз («Подробнее», затем
«Выполнить в любом случае»). На macOS первый раз открой приложение правым кликом и «Открыть»
или выполни `xattr -cr /Applications/Quadra.app`.

**Состояние платформ.** Quadra разрабатывается и каждый день используется на Windows. Версии
для macOS и Linux собираются и проверяются автоматически, но на живых машинах пока почти не
обкатаны: считай их предварительными и
[пиши в issues](https://github.com/Omibranch/quadra/issues), если что-то не так.

Версия для Android экспериментальная. Каждая сборка ставится на эмулятор, подключается к
тестовому серверу и проверяется: идёт ли через туннель трафик других приложений и чисто ли
проходит отключение. На настоящем телефоне она не запускалась ни разу.

## О режимах

- **Весь трафик (TUN)** требует повышенных прав, чтобы создать адаптер. На Windows приложение
  перезапускается от имени администратора; на macOS и Linux с правами запускается только ядро,
  через системный запрос пароля (на Linux это `pkexec`).
- Два туннеля на одной машине не уживаются. Если маршрут по умолчанию уже держит другой VPN,
  Quadra скажет об этом, а не станет поднимать второй туннель рядом.
- **Системный прокси** включается штатным способом системы: параметры интернета в Windows,
  `networksetup` в macOS, настройки GNOME или KDE в Linux. Там, где такой настройки нет,
  используй режим портов или весь трафик.
- **Android** работает в одном режиме, через системный VPN. Сама Quadra из туннеля исключена,
  чтобы её соединение с сервером не заворачивалось обратно.
- **Тайловые оконные менеджеры** (sway, i3, Hyprland и другие) определяются сами: окно
  убирает свою шапку и заставку, не имеет минимального размера и в узком тайле складывается
  в одну колонку.

## Сборка из исходников

Нужны [Node.js](https://nodejs.org) 22 или новее, [Rust](https://rustup.rs) и
[зависимости Tauri](https://v2.tauri.app/start/prerequisites/) для твоей системы.

```sh
npm install
node tools/fetch-xray.mjs     # скачивает Xray-core под эту машину и сверяет контрольную сумму
npm run tauri dev             # запустить
npm run tauri build           # собрать установщик
```

`npm run dev` без всего остального открывает интерфейс в браузере на подставных данных:
так быстрее всего работать над внешним видом.
